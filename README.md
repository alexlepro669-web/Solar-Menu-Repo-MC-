INSTRUCTIONS FOR DOWNLOAD :

1. Have Minecraft Launcher ready.

2. Make sure to have NeoForge 21.10.64 for Minecraft Java 1.21.10 (or another versions for futur release)

3. tap Win + R and type "%appdata%\.minecraft" and make sure to have on this folder a folder named "mods", if not, create it, with the EXACT name "mods".

4. Download the good Solar Menu version from one of the files.

5. Put your Solar Menu file into the "mods" folder.

6. Choose the neoforged installation that should have appeared

7. click the Play button.

8. Now you should be able to play with the mod !
